# Tomato Timer!
## A self-built, minimalist pomodoro timer because I didn't wanna drop 400php on a real one!

### Features
1. Uses Arduino Nano as the MCU.
2. KY-040 rotary encoder for the input, and SSD1306 OLED (12864) as the output.
3. Can be used to set a timer from a range of 1 minute to 60 minutes.

### V1.0
- This project is still in it's breadboard stage, although almost fully working.
- Considering a software update on QOL fixes like being able to pause the timer or adding a "Time's Up!" state, can do those in V1.1 lol.
- For V2.0, I plan to solder it onto a protoboard to make it more structurally stable.

### Just a little, personal background.

- This project is heavily inspired by the flip pomodoro timers that use a gyroscope.
- I just felt that I wanted to make my own with a tactile feel, but not necessarily a flip cube. Rather, I went for the rotary encoder since it was a part I had on hand and it provides that tactile analog feel that isn't provided by a purely digital timer from an app.
- I mostly worked on it in my free time.
- I was inspired to name it Tomato Timer because when I scrolled through PinDuoDuo listings, they're just translated from Chinese to English. So, it said "Tomato timer" everytime I saw a listing for the flip cube style timer.
- This Github was made for the purposes of documentation for Hackclub's program Pixl.
- Right now, I know the github looks really unprofessional. I'm still unsure if I want to keep it that way, but in any case I'll change that after the release of V2.
